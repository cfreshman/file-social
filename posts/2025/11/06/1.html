a new simple data persistence library for file-social

how it works
- the library exposes store.data
- set JSON-friendly objects on it!
- for example, store.data.words = ['hello', 'world']
- changes auto-save
remember:
client-side = localStorage (per-browser)
server-side = files (shared across devices)
