Welcome to file-social!


This is an example post showing how to create content.


Source: github.com/cfreshman/file-social


Features

  • Write HTML posts
  • Drop in images, videos, and text files
  • Self-hosted with easy deployment

Run npm run new to create your first post!


Tips

  • Organize by date: posts/2025/01/15/my-post.html
  • Or keep flat: posts/my-post.html
  • Pin important posts using public/config/-pins
