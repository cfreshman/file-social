# Markdown Example

This is an example markdown post for **file-social**.

## Features

Markdown files (`.md`) support:

- **Bold text** and *italic text*
- `inline code` and code blocks
- [Links](https://github.com)
- Lists (like this one!)

### Code Example

```javascript
const greeting = "Hello, world!";
console.log(greeting);
```

### Blockquote

> Markdown makes it easy to write formatted text.
> Just create a `.md` file in your `posts/` directory!

## How to Use

1. Create a `.md` file in `posts/`
2. Write your content using markdown syntax
3. View it in your feed with formatting

---

**That's it!** Your markdown will be automatically rendered with styling.
